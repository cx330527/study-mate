# 学伴 StudyMate

一个完整的学习助手网页项目，帮助你提问、拆解学习目标、安排任务和记录专注时间。

## 已实现的功能

- **学习概览**：今日任务、每日专注目标和最近七天的学习统计。
- **任务管理**：新增、编辑、完成、恢复、搜索和删除任务。
- **学习日历**：按周查看任务；支持本地模板和 AI 拆解目标，确认后才加入日历。
- **专注计时**：15/25/45 分钟专注、短休息、暂停、恢复、刷新后继续计时。
- **学习问答**：服务端调用 DeepSeek，多轮解释知识点。可选择主动分享未完成的学习计划。
- **学习提醒**：页面打开时，显示任务到时提醒和专注结束提醒；支持浏览器通知。
- **数据管理**：浏览器本地保存，JSON 备份导入和导出。

## 技术结构

React + TypeScript + Vinext，服务端运行于 Cloudflare Workers / Sites。界面和业务逻辑分开，算法、备份和 AI 网关有单元测试。

```text
浏览器界面 → 同源 /api/ai → 服务端 Secret → DeepSeek
     ↓
浏览器 localStorage：任务、专注记录和计时状态
```

AI 密钥不进入浏览器、GitHub 仓库或构建后的客户端文件。网页与源代码可以公开。AI 问答和 AI 计划只允许站主账号使用；匿名访客和其他已登录用户均不能消耗站主 API 额度。站主身份通过服务端 Secret `STUDY_OWNER_EMAIL` 校验，此值不发到浏览器。

## 本地运行

需要 Node.js 22.13 或更新版本，以及 npm。

```text
npm ci
npm run dev
```

打开终端显示的本地地址，通常是 `http://127.0.0.1:5173`。使用本地的 `/signin-with-chatgpt?return_to=/` 登录入口建立开发用测试身份。该模拟身份只在本机开发服务器启用，生产构建不会携带此模拟登录。

任务、日历和专注计时不需要 API 密钥。启用本地问答时，在忽略提交的 `.dev.vars` 中配置：

```text
DEEPSEEK_API_KEY=在本机填入自己的密钥
DEEPSEEK_MODEL=deepseek-flash
STUDY_OWNER_EMAIL=你的站主登录账号邮箱
```

不要把真实值填进 `.env.example`，也不要为密钥添加 `NEXT_PUBLIC_` 前缀。托管部署应使用平台的服务器 Secret 设置，不上传本地密钥文件。

```text
node --test tests/*.test.mjs
npx tsc --noEmit
npm run build
```

## 数据与提醒的实际范围

任务、记录和计时状态仅保存在当前浏览器，不自动跨设备同步。清理浏览器数据会移除记录，建议定期导出备份。对话只保存在页面内存，刷新会清空；发送的问题会经过服务器传递给 DeepSeek。勾选“分享学习计划”后，最多八项未完成任务会作为背景发送。

计时按截止时间计算，能从页面刷新或设备休眠中恢复；它不检测你是否实际看书。只有完成的专注时段进入统计。关闭网页后，程序不会主动推送提醒或在后台监督。

AI 回答可能有误，应结合教材核对。AI 计划先经过格式校验，再由用户预览确认；不会自行修改任务或执行代码。

## 发布

项目保留 Sites 的构建集成。第一次部署时创建自己的 Site，并使用平台工具绑定自己的项目 ID；不要使用他人的 Site ID。生产网页允许公开访问，API 路由会核对站主身份和同源请求。任务、日历、专注和本地备份向访客开放。只有站主登录后可以使用 AI；访客数据保存在各自浏览器。不要移除服务端站主校验后直接开放个人付费 API。

接口限制为每个用户、每个运行实例一分钟十次请求，并限制输入和输出长度。这是基础防护，不是账户级费用上限；如需费用上限，请使用模型服务商提供的预算功能。

DeepSeek 调用格式参考：[官方文档](https://api-docs.deepseek.com/zh-cn/)。
